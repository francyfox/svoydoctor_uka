# Контент и тон коммуникации

Источник: разбор ~25 публикаций из ленты @svoydoctor_uka за период 02.2024–07.2026.

## Тематические кластеры контента

1. **Промо/акции** — стерилизация/кастрация со скидкой, сезонные предложения. Всегда с чётким CTA: телефон/WhatsApp, адрес, "по предварительной записи, количество мест ограничено".
2. **Организационные посты** — режим работы в праздники, внеплановые выходные, изменения графика. Публикуются заранее ("Планируйте визит заранее").
3. **Просветительский контент** — разбор конкретных тем: опасность пироплазмоза (бабезиоза) у собак, безопасность вакцинации, токсичные для животных цветы, польза питьевого фонтанчика для кошек. Тон — экспертный, но доступный, с эмодзи-акцентами (❗️🔬🐾), объясняют "на пальцах".
4. **Юмор/behind-the-scenes** — короткие рилсы про будни ассистентов ("POV: когда ты ассистент", "немного юмора в ленту", "на самом деле мы любим наших ассистентов"). Хэштеги: `#ветеринарустькаменогорск #ветеринария #ветеринарнаяклиника #юмор`. Это очеловечивает бренд, показывает команду.
5. **Зоозащита** — поиск дома для стерилизованных кошек ("ищет любящий дом"), сбор доноров крови для собак и кошек, сотрудничество с приютом «Досым» (день рождения приюта отмечен в аккаунте).
6. **Вовлекающий/развлекательный** — например, пост "вы кто по натуре, кошка или собака" с призывом комментировать.
7. **Вакансии** — периодически ищут сотрудников через свой аккаунт и локальные паблики вакансий (`vakansiya_ukg`, `rabota_u.ka`, `rabota__oskemen`).

## Тон голоса

- Дружелюбный, тёплый, "по-соседски" — обращаются на "вы", но без канцелярита
- Активно используют эмодзи как визуальные маркеры структуры (❗️🔬📍☎️🎉), это часть визуального языка постов-карточек
- Экспертность подкрепляется конкретикой: дозировки, названия препаратов (Симпарика, Бравекто, НексгарД, Форесто, Килтикс, Адвантикс, Фиприст, Больфо), названия анализов — не боятся быть техничными для аудитории, которая уже неравнодушна к теме
- Много прямых призывов к действию с полным набором контактов в каждом промо-посте (это стоит взять за паттерн для сайта: каждый блок услуги = контакты рядом)

## Наблюдение для UX сайта

- У бизнеса нет единого "статичного" прайса на приём — цены живут в постах/акциях. Сайту нужен гибкий блок "актуальные акции" (или интеграция с Instagram/каналом), а не только зашитая таблица цен.
- Много контента рассчитано на "успокоить тревожного владельца" (посты о симптомах, объяснение вакцинации) — на сайте уместен раздел FAQ / "когда срочно к врачу".
- Явный социальный/зоозащитный компонент — можно сделать блок "мы помогаем бездомным животным" как элемент доверия и человечности бренда.
- Команда молодая и дружелюбная — фото персонала в реальной обстановке (не стоковые) хорошо ложатся в раздел "о клинике"/"команда".
