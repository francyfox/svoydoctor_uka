# Визуальная идентичность (наблюдения из Instagram)

Источник: логотип профиля и оформление сторис/постов @svoydoctor_uka. Это не официальный брендбук (его не существует) — это реконструкция сложившегося визуального языка, от которого можно оттолкнуться в дизайне сайта.

## Логотип

Круглый значок: белый/кремовый фон, внутри — силуэт в один цвет (тёмный фиолетовый/баклажановый), составленный из головы лошади, кота и собаки, объединённых в одну фигуру. Рядом подпись "Свой Доктор" тем же цветом, шрифт с засечками, слегка декоративный.

Важная деталь: **в лого есть лошадь**, не только кошка/собака — отражает, что клиника работает и с сельхоз/крупными животными (в описании зоомагазина упоминаются "препараты для с/х животных"). Стоит решить на этапе UX, показывать ли это на сайте явно (может расширить восприятие аудитории) или сфокусироваться на основном сегменте (кошки/собаки), который явно доминирует в контенте.

## Цветовая палитра (наблюдаемая)

- **Основной**: глубокий фиолетовый / баклажановый (лого, акцентные плашки) — похож на `#5B1A73`–`#6A1B7A` диапазон, нужно уточнить точный HEX через пипетку на выгруженном лого
- **Вторичный**: розовый/маджента градиент — используется в промо-карточках (акция на стерилизацию), градиент розовый → фиолетовый
- **Нейтральные**: белый/кремовый фон под лого и в карточках, чёрный текст на светлых карточках
- **Акценты в сторис-карточках**: голубой (медицинский, для лабораторных прайс-карточек — карточки "Прайс" сделаны в сине-фиолетовом градиенте с текстурой медицинских перчаток/пробирок на фоне)

Наблюдение: у бизнеса нет единой строгой палитры для всех промо-материалов — разные посты используют разные градиенты (фиолетовый для стерилизации, сине-фиолетовый для прайса лаборатории). Для сайта стоит **консолидировать** это в 1 основную + 1–2 акцентные цвета, а не копировать всё многообразие.

## Стиль фотографии

- Реальные фото животных-пациентов (не стоковые) — коты, кролики, часто крупным планом, естественный свет
- Фото персонала в рабочей обстановке — реальные, неформальные, в медицинской форме, за работой (УЗИ-аппарат, осмотр)
- Юмористические короткие видео (Reels) с персоналом — неформальный, живой контент
- Промо-карточки — типичный "цифровой флаер" стиль: крупный заголовок, иконки-пункты списка (галочки/иконки в кружках), контакты внизу крупным шрифтом

## Иконография

В промо-карточках используют простые линейные/заполненные иконки в кружках (профилактика, спокойствие, безопасность) — минималистичный стиль, подходит для переноса в UI сайта как основа для карточек услуг.

## Рекомендация для сайта

- Взять фиолетовый как основной брендовый цвет (уже узнаваем по лого и активнее всего используется), добавить один тёплый нейтральный (кремовый/белый) и один акцент (например, мягкий розовый или мятный для "здоровья/чистоты")
- Использовать реальные фото животных-пациентов и команды вместо стоков — это уже сильная сторона бренда
- Иконки-в-кружках для списков услуг — прямое продолжение их текущего визуального языка из промо-карточек
- Уточнить точные HEX-коды нужно вручную (через пипетку/Figma) с оригинального файла лого — на этапе сбора у нас есть только скриншот с JPEG-сжатием Instagram
