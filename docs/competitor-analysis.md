# Конкурентный анализ

Собрано 2026-07-17. Два ориентира: прямой региональный конкурент с сайтом (ZOOVITA, тот же город) и топовая клиника по стране для оценки верхней планки (Талисман, Алматы).

---

## 1. ZOOVITA — прямой конкурент, тот же город (Усть-Каменогорск)

**Сайт**: [zoovita.kz](https://www.zoovita.kz/)

### Масштаб — вот где основной контраст со «Свой Доктор»

- Работают с 2009 года (15 лет на рынке)
- **3 филиала** в Усть-Каменогорске, один из них — **круглосуточно, без выходных**
- Заявляют «69 000+ спасённых жизней»
- Команда: **30+ ветеринарных врачей** с разделением по отделениям (терапия, хирургия, лаборатория, анестезиология и стоматология, ОРИТ), плюс отдельный административный блок — директор, отдел маркетинга, бухгалтерия, несколько администраторов, груминг, кинолог, «зооняня»
- При клинике работает сеть зоомаркетов «ZOOVITAMARKET» и собственная школа ветеринарной медицины «ZoovitaStudy»
- Активны в соцсетях по всем направлениям: TikTok, VK, YouTube, OK.ru, Instagram

**Вывод**: это не конкурент уровня «кабинет vs кабинет» — это локальный ветеринарный холдинг. Не стоит пытаться конкурировать с ними масштабом на сайте, но стоит перенять то, что реализуемо без штата в 30+ человек (см. раздел "Что взять" ниже).

### Структура сайта

Главная (одностраничник с якорями) + отдельные страницы:
- Главная — hero, статистика (2009 / 24/7 / 3 филиала / 69000+), карточки услуг, видео-тур по филиалу (встроенный YouTube), блок акций, контакты всех филиалов
- «Услуги и цены» → ведёт к **полному прайс-листу** (`price_full.html`) — фактически прайс-лист на десятки страниц: приём, паспорт/вакцинация/чипирование, визуальная диагностика (рентген, УЗИ, ЭКГ), лаборатория (десятки видов анализов, вплоть до генетики и гистологии с отправкой в Москву/СПб), КТ, МРТ, ЭЭГ, С-дуга (рентгеноскопия), терапия/манипуляции, амбулаторная и полостная хирургия, косметическая и онкологическая хирургия, анестезиология, ортопедия/травматология — **сотни позиций с точными ценами**, включая градацию по весу животного
- «Команда» — отдельная страница с фото и должностью каждого сотрудника
- «Акции» — блок скидок (-20% на кастрацию/стерилизацию, вакцинацию, чипирование, паспорта; -10% на зоогостиницу)
- Отдельная услуга-фича: **«Получить результаты анализов онлайн»** — CTA-кнопка на главной, ведёт на портал для клиентов
- Контакты — 3 адреса с индивидуальным графиком и телефоном для каждого филиала, ссылка на 2ГИС для каждого

### Визуальный стиль

- Основной цвет — **фиолетовый/пурпурный** (похож на «Свой Доктор» — совпадение довольно неожиданное, оба бренда независимо выбрали фиолетовый для вет.тематики)
- Светлый лавандовый фон, крупная типографика в hero
- Лого: текст "ZOOVITA" с силуэтами лошади/собаки/кошки внутри букв, двуязычная подпись (казахский + русский)
- Карточки услуг выложены asymmetric-сеткой (разная высота карточек, лёгкая fade-in анимация при скролле)
- Встроенное видео виртуального тура по филиалу — сильный элемент доверия
- Плавающая кнопка WhatsApp внизу слева

### Что стоит перенять для «Свой Доктор» (реалистично, без штата в 30 человек)

1. **Отдельная страница/PDF с полным прайсом** — даже если позиций немного, наличие структурированной таблицы цен на сайте резко повышает доверие по сравнению с «звоните, узнавайте»
2. **Блок акций на сайте** (у клиники уже есть регулярные акции в Instagram — просто нужно дублировать на сайт с датами)
3. **2ГИС-ссылка рядом с адресом** — у «Свой Доктор» уже есть эта привычка в Instagram-сторис, перенести на сайт
4. **Видео/фото реального кабинета** — даже 30-секундный ролик "как выглядит наш кабинет" сильно поднимает доверие для клиники без сайта
5. **WhatsApp-кнопка плавающая по всему сайту** — у клиники уже основной канал записи именно WhatsApp

## 2. Ветклиника «Талисман» — ориентир верхнего уровня (Алматы)

**Сайт**: [vetclinic.kz](https://vetclinic.kz/) | Отдельный благотворительный проект: [donate.vetclinic.kz](https://donate.vetclinic.kz/)

Выбрана как референс "топ по стране": отмечена наградой "Выбор года 2019", крупнейший город Казахстана, зрелый веб-продукт.

### Функциональность, которой нет ни у «Свой Доктор», ни у ZOOVITA

- **«Личный кабинет»** на сайте — клиент может: записаться на приём онлайн без звонка, видеть историю посещений питомца, диагнозы и результаты анализов в своём аккаунте. Это уровень полноценного пациент-портала, редкость для регионального рынка РК
- **Услуга «Внимательный уход»** — платная опция для животных в стационаре: персонал кормит, гладит, укрывает одеялом для снижения стресса питомца — эмоциональный, человечный дифференциатор, который легко считывается клиентом
- Отдельный **благотворительный микросайт** (donate.vetclinic.kz) с современным дизайном (арочные обрезки фото, пастельная палитра, игривая предметная съёмка животных в костюмах) — показывает, что зоозащитная деятельность (уже есть и у «Свой Доктор» через приют «Досым») может быть оформлена как отдельный, визуально сильный продукт, а не просто пост в ленте

### Структура сайта

Навигация: О нас (дропдаун), Мы помогаем, Ветеринарные услуги (дропдаун: Вет.Клиника / Терапия / Хирургия / Диагностика), Контакты, Вет-Блог, поиск.

- Раздел услуг — не просто список, а лендинг с объяснением философии клиники ("мы изучили других и дополнили тем, чего не хватало на рынке")
- **Вет-Блог** — контент-маркетинг, отдельный раздел с образовательными статьями (аналог просветительских постов «Свой Доктор» в Instagram, но на своей площадке — работает на SEO)
- Полноценная страница команды врачей с фото (аналогично ZOOVITA)
- Отзывы клиентов встроены прямо в структуру страниц (не вынесены на отдельную площадку)
- Блок явных УТП иконками: команда профессионалов, современное оборудование, комфортная зона ожидания с кофе, круглосуточная охраняемая парковка

### Визуальный стиль

- Более сдержанная, "корпоративная" эстетика на основном сайте (тёмный header, бирюзовый/оранжевый акцент в иконках) — контрастирует с игривым донат-сайтом, где пастель и юмор
- Реальные фото врачей по кругу — тот же паттерн, что у ZOOVITA (команда с лицами — общий стандарт индустрии в РК)

Изображение: `docs/media/competitors/talisman-donate-hero.jpg`.

### Что стоит перенять для «Свой Доктор»

1. **Личный кабинет — не обязателен на старте**, но стоит заложить в архитектуру возможность добавить его позже (история посещений — то, о чём хозяева питомцев реально просят)
2. **Вет-блог на сайте**, а не только в Instagram — просветительский контент у «Свой Доктор» уже есть и хорошего качества (пост про пироплазмоз, про вакцинацию) — грех не переиспользовать его на сайте для SEO
3. **Явные УТП-иконки** над fold — у «Свой Доктор» такие УТП фактически есть (собственная лаборатория на месте, стационар, доказательная медицина), просто разбросаны по разным постам — на сайте нужно свести их в один блок
4. **Отдельный по-настоящему тёплый визуальный подход к зоозащитной теме** (донат-сайт Талисмана) — у «Свой Доктор» есть и посты "ищет дом", и донорство крови, и сотрудничество с приютом «Досым» — это готовый материал для отдельного эмоционального блока на сайте

## Итоговое позиционирование «Свой Доктор» на фоне рынка

| | Свой Доктор | ZOOVITA (тот же город) | Талисман (топ РК) |
|---|---|---|---|
| Сайт | нет (только Instagram) | есть, простой лендинг + прайс | есть, зрелый, с личным кабинетом |
| Филиалов | 1 | 3 | 1 (крупный) |
| Штат врачей (видимый) | не указан явно | 30+ | 15+ |
| Круглосуточность | нет (Пн-Пт 8-18, Сб 9-14) | да, минимум 1 филиал 24/7 | без выходных |
| Полный прайс в открытом доступе | только лаборатория | да, детальнейший | частично |
| Личный кабинет / история питомца | нет | нет (только результаты анализов онлайн) | да |
| Зоозащитная деятельность | да (посты, донорство, приют) | не обнаружено на сайте | да, отдельный сайт |
| Тон коммуникации | тёплый, юмор, локальный | корпоративный, статистика/масштаб | смешанный: корпоративный сайт + игривый донат-проект |

**Вывод для UX/UI**: «Свой Доктор» не может и не должен конкурировать масштабом с ZOOVITA или уровнем tech-стека с Талисманом. Реалистичная стратегия сайта — взять то, что уже реально сильно в текущем контенте (тёплый тон, экспертные посты, зоозащита, собственная лаборатория) и упаковать это в такую же по духу, но компактную и честную структуру: главная с УТП → услуги (с понятным прайсом там, где он есть) → акции (актуальные) → команда/о клинике → зоозащита как отдельный тёплый блок → контакты с 2ГИС и WhatsApp.
